# Quiz App: React + TypeScript + Vite + JSON Server

## Install packages

```bash
npm install
```

## Start the JSON server

```bash
npx json-server db.json
```

```bash
JSON Server started on PORT :3000
http://localhost:3000
```

## Test the server

```bash
curl http://localhost:3000/questions
```

## Build the React App (or start it in dev mode)

```bash
// Open a new terminal window (keep the JSON Server running)

npm run dev // dev mode

npm run build // build the app
```
